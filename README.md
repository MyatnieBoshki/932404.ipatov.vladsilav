## Технологии и подходы

- **Flexbox** используется для одномерных макетов: горизонтальное адаптивное навигационное меню и ряд карточек жанров игр.
- **CSS Grid** используется для двумерного макета дашборда статистики игрового времени (3 колонки).
- **Медиа-запросы** обеспечивают адаптивность под планшеты (`max-width: 1024px`) и мобильные устройства (`max-width: 600px`), без горизонтальной прокрутки на любом разрешении.
- **CSS-переменные** (`:root`) задают основную цветовую палитру (тёмно-фиолетовый фон, неоново-зелёный акцент) и основной шрифт.
- Реализованы все три типа позиционирования: `static` (секции и aside), `relative` (карточки проектов как точка отсчёта) и `absolute` (бейдж внутри карточки).
- Добавлены псевдоклассы `:hover`, `:active`, `:focus` и `:visited` для интерактивных элементов (кнопки, поля формы, ссылки, карточки).
- Семантическая вёрстка: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
- Контрастность текста к фону проверена и составляет не менее 11:1, что превышает минимальный порог WCAG (4.5:1).
- **JavaScript** (`js/script.js`) добавляет интерактивную логику: ввод имени через `prompt`, приветствие и статистика через `alert`/`console.log`, обработка массива часов с помощью собственных функций (`findMax`, `filterByCondition`, `sumArray`) и циклов.

## Разделы страницы

- **Навигация** — меню с переходами по якорям к основным разделам.
- **Любимые жанры игр** — карточки на Flexbox с иконкой и описанием механики жанра.
- **Статистика игрового времени** — дашборд на CSS Grid (часы в RPG, победы в шутерах, пройденные квесты).
- **Проекты** — карточки с эффектом «поднятия» при наведении.
- **Обратная связь** — форма с полями имени, email и сообщения.
